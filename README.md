# Signup Automation

## 1. How to Run the Script

**Prerequisites:**
- Python 3.14
- Google Chrome
- Selenium 4.41.0
- Gmail IMAP access for OTP verification

**Installation:**

```bash
pip install selenium==4.41.0
```

**Run the automation script:**

```bash
python signup_automation_script.py
```

The script automatically completes the signup process, retrieves the email OTP, fills in the required details, uploads the document, and submits the form.

Website: https://authorized-partner.vercel.app/
