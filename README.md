# -SIGNUP-AUTOMATION
This project automates the signup process using selenium and python
PREREQUISITES: 
Before running the scripts, make sure you have: Python 3.14, Google Chrome browser installed, pip package manager
EXECUTION AND COMMAND:
Clone this repo in your IDE and type python signup_automation_script.py in your terminal
ENVIRONMENT/SETUP:
Language-python 3.14
Framework-Selenium 4.41.0
Browser-Google Chrome
Driver-chromedriver automatic managed by selenium
IDE-pycharm
Operating System-macOS
